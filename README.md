### Automated Mail Processing System

# О проекте

Automated Mail Processing System — система автоматической обработки корпоративной почты, предназначенная для сортировки входящих обращений сотрудников по тематическим категориям.

Основная особенность проекта — устойчивость к появлению новых типов обращений. Если письмо невозможно автоматически классифицировать, система позволяет пользователю вручную определить категорию и автоматически обучается на этом решении для будущих запусков.



# Основные возможности

1. Автоматическая классификация писем

2. Проверка корректности данных перед запуском

4. Интерактивная обработка неизвестных обращений

5. Самообучающийся словарь категорий

6. ### Логирование действий AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAa

7. Сбор статистики по загруженным письмам

8. Обработка ошибок и поврежденных файлов

9. Полноценное тестовое покрытие

## Этап 1. Предварительная валидация

Перед запуском основной обработки выполняется проверка.

Валидатор автоматически проверяет:
1. наличие папки с исходными письмами
2. наличие писем в папке для последующей обработки
3. наличие конфигурационных файлов
Если обнаружена критическая ошибка, запуск обработки блокируется до её исправления, а пользователю поступает сообщение об ошибке и ее типе.

Пример запуска:
- происходит автоматически во время запуска программы
- также в терминале можно написать python validate.py
- автоматически через: ./run.sh


## Этап 2. Автоматическая классификация

После успешной проверки система анализирует содержимое каждого письма.
Для каждой категории хранится набор ключевых слов.

Пример:

Категория выбирается по количеству найденных совпадений.

## Этап 3. Интерактивная обработка неизвестных писем

Одной из основных задач проекта является устойчивость к новым типам обращений.

Если письмо не соответствует ни одной существующей категории, система не помещает его в папку “unknown” автоматически.

Вместо этого запускается интерактивный режим.

Категория не определена.

Далее пользователю предоставляется выбор из всех существующих категорий, где он самостоятельно может определить категорию этого письма или отправить письмо в неопознанные(12)

# Самообучающийся словарь

После выбора категории система анализирует текст письма и сохраняет новые ключевые слова для выбранной категории.

Например:

Исходное письмо содержит слова:

"ковер, абракадабра(допустим)..."

Пользователь относит письмо к категории:
<hr>

После подтверждения словарь автоматически обновляется:
{
    "hr": [

        "отпуск",
        "больничный",
        "сотрудник",
        "onboarding",
        "оформление",
        "увольнение",
        "вакансия",
        "собеседование",
        "hr",
        "кадровый"
        "абракадабра"
        "ковер"
        ...
    ]
}

# Накопление знаний между запусками

Обновленный словарь сохраняется, и при дальнейшей обработке и распределение файлов, добавленные слова будут учитываться и распределение других писем произойдет по аналогии и мнение пользователя спрашиваться не будет.
Таким образом классификатор постепенно адаптируется к реальным данным без изменения исходного кода.

Это позволяет:
1. уменьшать количество неопознанных писем
2. автоматически учитывать новые типы обращений
3. повышать точность классификации
В целом это уменьшает количество времени, которое пользователю понадобиться на ручной перебор и распределение неопознанных чисел.


## Работа с ошибками

Система предусматривает обработку следующих ситуаций:

- неподдерживаемой расширение файла
- поврежденный или нечитаемый файл
- пустые или файлы без ключевых слов(на усмотрение пользователя//переносятся в unknown)
- ошибка чтения файла

Работа приложения не прерывается при обработке отдельных ошибочных файлов, а пользователю в итоговой статистке будет отмеченно, какие файлы не удалось распознать и почему.

## Логирование

Все действия записываются в журнал.
С помощью логера пользователю выводится дата и время, а также информация о внесение файла или его ошибке.
